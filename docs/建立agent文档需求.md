# 建立 Agent 文档需求

## 一、概述

本文档描述了 RxyCode Agent 的文档需求和规范。

## 二、核心需求

1. **系统提示词文档** - 定义 Agent 的行为规范和输出格式
2. **UI 交互文档** - 定义终端 UI 的交互规则
3. **工具使用文档** - 定义 Agent 可用的工具及其使用方式
4. **缓存策略文档** - 定义缓存机制和优化策略

## 三、输出格式

Agent 需要使用以下格式进行输出:

- <ask> - 向用户提问
- <thinking> - 内部思考过程
- <final_answer> - 最终回答

- docs/ - 文档目录
  - 建立agent文档需求.md - 本文档
  - RxyCode_PLAN.md - 项目计划
