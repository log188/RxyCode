# RxyCode 快速入门指南

欢迎使用 RxyCode！这是一个通用 AI Agent，可以帮助你检索信息、操作文件和命令，并完成软件工程与多步骤协作任务。

## 快速开始

### 1. 启动 RxyCode

在命令行中输入以下命令启动 RxyCode：

```bash
RxyCode
```

RxyCode 仅使用当前 Ink 前端；启动失败时会直接显示缺失的 Node.js 或前端运行文件，不会切换到旧界面。

### 2. 配置模型

首次使用需要配置 AI 模型。使用以下命令添加模型：

```bash
/addmodel
```

按照提示输入：
- 模型名称（如：deepseek-v4-flash）
- API 密钥
- API 地址（如：https://api.deepseek.com）

### 3. 选择工作模式

RxyCode 提供三种工作模式：

- **构建模式** (`/build`)：默认模式，可以执行所有操作
- **规划模式** (`/plan`)：只读分析，不会修改文件
- **编排模式** (`/compose`)：先规划任务，再按依赖关系执行

使用以下命令切换模式：
```bash
/plan    # 切换到规划模式
/build   # 切换到构建模式
/compose # 切换到编排模式
```

### 4. 开始使用

直接输入你的需求，RxyCode 会自动理解并执行：

```
帮我写一个 Python 函数计算斐波那契数列
```

```
分析这个项目的结构
```

```
修复这个 bug
```

## 常用命令

### 帮助命令
- `/help` - 显示所有可用命令
- `/tutorial` - 交互式教程
- `/quickstart` - 快速入门指南
- `/examples` - 使用示例

### 模型管理
- `/addmodel` - 添加新模型
- `/models` - 列出所有模型
- `/model <name>` - 切换模型

### 记忆管理
- `/memory add <text>` - 添加记忆
- `/memory list` - 列出所有记忆
- `/memory remove <id>` - 删除记忆
- `/memory search <query>` - 搜索记忆

### 任务队列
- `/queue` - 查看任务队列
- `/queue add <prompt>` - 添加任务到队列
- `/queue run` - 运行所有队列任务

### 对话管理
- `/save-chat-<name>` - 保存当前对话
- `/load-chat-<name>` - 加载已保存的对话
- `/list-chats` - 列出所有已保存的对话

### 其他命令
- `/clear` - 清除对话上下文
- `/language` - 切换语言
- `/cache` - 查看缓存统计
- `/thinking` - 切换思考面板显示

## 快捷键

- `Tab` - 切换工作模式
- `Ctrl+C` - 退出程序
- `Ctrl+?` - 显示帮助对话框
- `Ctrl+X` - 取消当前操作
- `Ctrl+S` - 发送消息
- `Ctrl+E` - 外部编辑器

## 提示和技巧

1. **详细描述需求**：尽量详细描述你的需求，包括技术栈、约束条件等
2. **使用自然语言**：直接用自然语言描述需求，RxyCode 会自动理解
3. **查看帮助**：遇到问题时使用 `/help` 查看可用命令
4. **切换模式**：根据任务类型选择合适的模式
5. **使用记忆**：使用 `/memory` 保存重要信息
6. **任务队列**：使用 `/queue` 管理多个任务

## 常见问题

### Q: 如何保存当前对话？

### Q: 如何查看可用命令？
A: 输入 `/help` 查看所有可用命令。

### Q: 如何取消当前操作？
A: 按 `Ctrl+X` 取消当前操作。
